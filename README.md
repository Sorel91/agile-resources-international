# Agile Resources International

Copie du site vitrine [agileresources-intl.com](https://agileresources-intl.com), hébergé sur Hostinger.

## Déploiement

Le contenu du dépôt correspond aux fichiers à placer dans le dossier `public_html` de l’hébergement.

Le traitement des formulaires est assuré par `contact.php` et nécessite un hébergement PHP.
